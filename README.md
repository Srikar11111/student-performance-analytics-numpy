# Student Performance Analytics using NumPy

A practical data analysis project built using **Python and NumPy** to analyze student performance and demonstrate core numerical computing concepts used in data science and machine learning.

## Project Overview

This project analyzes student marks, attendance, and assignment scores to generate useful performance insights.

It demonstrates how NumPy can be used for:

- Numerical data processing
- Statistical analysis
- Data validation
- Feature engineering
- Data normalization and standardization
- Boolean filtering
- Ranking and classification
- Vectorized operations
- Matrix multiplication
- NumPy data storage

- NumPy

## Analysis Performed

The project calculates:

- Individual student averages
- Median and standard deviation
- Student performance scores
- Student grades
- Top and lowest performers
- Subject-wise statistics
- High-performing students
- Students requiring improvement
- Student rankings
- Overall class statistics
